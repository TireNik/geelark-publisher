# GeeLark Publisher

Сервис на Django для подготовки и запуска публикаций роликов через GeeLark.
Проект запускается в Docker: приложение Django/Gunicorn и Nginx.

## Первый запуск

1. Создайте локальный файл настроек из шаблона:

   ```bash
   cp .env.example .env
   ```

2. В файле `.env` укажите настоящий `DJANGO_SECRET_KEY` и `GEELARK_TOKEN`.
3. Запустите сервис:

   ```bash
   docker compose up -d --build
   ```

4. При необходимости примените миграции:

   ```bash
   docker compose exec app python manage.py migrate
   ```

## Excel для публикаций

Обязательные колонки: профиль, соцсеть, ссылка на видео, описание и время
публикации. Для YouTube можно добавить шестую колонку — короткий заголовок.
Он не может превышать 100 символов. Если шестая колонка пуста, сервис берёт
текст из колонки с описанием; длинный текст не обрезается молча, а отмечается
понятной ошибкой до запуска публикации.

## Что не хранится в Git

В репозиторий намеренно не попадают `.env`, база SQLite, загруженные ролики,
логи, архивы и SSH-ключи. Это защищает доступы и не раздувает историю Git.

Перед изменениями создавайте отдельную ветку, проверяйте изменения и только
после этого обновляйте рабочий сервер.
